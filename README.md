# Guará Bangalôs — site de demonstração

Site de demonstração de uma hospedagem ecolodge na Chapada dos Veadeiros (GO).
Roda inteiro no navegador (HTML, CSS e JavaScript, sem servidor).

**Dados fictícios:** reservas, hóspedes, telefones, e-mails e dados de PIX são inventados.
Nada é enviado nem cobrado de verdade.

## Acessos de demonstração

| Perfil | Usuário | Senha |
|---|---|---|
| Pousada (Gestão) | `admin` | `guara123` |
| Hóspede | `maria@teste.test` | `demo1234` |

## O que dá para testar

- Reserva com calendário, regras de estadia e total na hora
- Conta de hóspede: cadastro, login, minhas reservas, cancelamento
- Gestão: painel do dia, reservas, ocupação, hóspedes, e-mails simulados
- Editar site: textos, fotos, preços, chalés, contato e mapa, com prévia ao vivo

As alterações feitas ficam salvas só no navegador de quem testou.
